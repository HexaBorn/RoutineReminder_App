# 🔔 RoutineReminder - Official Download & Setup Guide

Welcome to the official distribution repository for **RoutineReminder**. Here you can find the latest installers and binaries for Windows and Linux platforms.

---

## 🚀 About RoutineReminder

**RoutineReminder** is a smart and lightweight desktop application designed to help users manage their daily routines, classes, tasks, and schedules seamlessly with timely notifications.

### Key Features:
- 📅 **Schedule Management:** Easily organize and customize your daily routines.
- 🔔 **Timely Notifications:** Never miss a class, task, or meeting.
- 💻 **Cross-Platform:** Available for both Windows and Linux OS.
- ⚡ **Lightweight & Fast:** Minimal resource usage with maximum efficiency.

---

## 📥 Download & Installation

### 🪟 Windows Users
1. Go to the **[Releases](../../releases)** section on the right side of this page.
2. Download the latest `.exe` installer (e.g., `RoutineReminder-Setup.exe`).
3. Double-click the downloaded file and follow the installation wizard.

---

### 🐧 Linux Users (Ubuntu / Debian / Mint)
1. Download the `.deb` package file from the **[Releases](../../releases)** page.
2. Open your terminal in the downloaded directory and run:
